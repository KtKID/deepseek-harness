# Plugin Doctor 未显示修补单

> 修复时间：2026-08-17 00:45
> 修复人：Codex (x-fix)

## Bug 描述

用户执行 `pnpm run dev:web` 后打开 Web 设置，插件分区仅显示“插件配置”和“插件列表”，缺少“插件诊断”。

## 根因分析

`pnpm run dev:web` 是 Client 插件 bundle 的 watch-build 与 HMR 驱动，它不启动 Web profile。新增 Plugin Doctor 同时增加了一个 Web bundle Loader 行；运行中的旧 Web 进程持有启动时组合，Client bundle watcher无法替该进程重新装配 bundle patch。源码 CLI 在准备 profile 时还会把新增 workspace 依赖补入 `~/.dsh/profiles/node_modules`，这一准备步骤由 `pnpm dsh web` 完成。

## 修复方案

执行源码 CLI 的 profile 准备与 Web 启动流程：先完成一次项目 build，再用 `pnpm dsh web` 启动或重启 Web。开发时可在第二个终端运行 `pnpm run dev:web`，让已装配的 Client 插件在源码变化后触发 HMR。
